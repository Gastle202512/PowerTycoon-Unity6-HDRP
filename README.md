# PowerTycoon - Unity 6 HDRP

Ein strategisches PC-Spiel über Energieproduktion und -management, entwickelt mit **Unity 6** und **HDRP (High Definition Render Pipeline)**.

## 🎮 Gameplay-Konzept

Verwalte dein Energieimperium:
- 🏭 Baue verschiedene Kraftwerke (Kohle, Gas, Wind, Solar, Kernkraft)
- ⚡ Produziere und vertreibe Energie
- 💰 Maximiere Profit und Expansion
- 🌍 Achte auf Umweltauswirkungen
- 📊 Verwalte Ressourcen und Budget

## 🛠️ Technologie-Stack

- **Engine**: Unity 6
- **Rendering**: HDRP (High Definition Render Pipeline)
- **Scripting**: C#
- **Platform**: PC (Windows/macOS/Linux)

## 📁 Projektstruktur

```
Assets/
├── Scripts/
│   ├── Core/           # Kern-Spiellogik
│   ├── Systems/        # Game-Systems (Energie, Wirtschaft, etc.)
│   ├── UI/             # UI-Controller
│   └── Utilities/      # Hilfsklassen
├── Prefabs/            # GameObject-Templates
├── Scenes/             # Spiel-Szenen
├── Models/             # 3D-Modelle
├── Materials/          # HDRP-Materialien
├── VFX/                # Visual Effects
├── Audio/              # Sound und Musik
└── Data/               # Gameplay-Daten
```

## 🚀 Getting Started

1. Unity 6 installieren
2. HDRP-Projekt erstellen oder aktivieren
3. Repository clonen
4. Projekt in Unity öffnen
